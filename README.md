# Dude Bartlett — Interactive Resume

A Palm Springs atomic mid-century modern digital resume, hosted on GitHub Pages.

- `index.html` — the interactive resume. Skills are clickable and light up the projects and positions where each skill was used. Job positions unfold with animated detail panels.
- `print.html` — the elegant one-page printable resume, linked from the main page as "(Print Copy of Resume here)". Sized for US Letter.

Built by Dude in the Desert Studios.
